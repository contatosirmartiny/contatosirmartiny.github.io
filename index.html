SirMartiny Analytics

Acompanhamento do canal SirMartiny para apoiar o planejamento de conteúdo.

Sobre o aplicativo

O SirMartiny Analytics é uma ferramenta utilizada pela equipe responsável pelo canal SirMartiny no YouTube. Com a autorização do proprietário, consulta relatórios para acompanhar o desempenho dos vídeos e organizar o planejamento editorial.

Utiliza a YouTube Data API e a YouTube Analytics API com permissões de leitura. Os dados consultados incluem informações dos vídeos, visualizações, tempo assistido, inscritos, fontes de tráfego, termos de pesquisa agregados, retenção quando disponível e receita estimada.

Acesso e armazenamento

A coleta é executada no computador da equipe. A autorização acontece na página oficial do Google, iniciada pelo aplicativo local. O aplicativo não publica, modifica ou exclui vídeos.

Este site é informativo: não recebe credenciais nem disponibiliza os relatórios privados do canal. Consulte a Política de Privacidade para conhecer o uso dos dados, o armazenamento e as opções de revogação.
